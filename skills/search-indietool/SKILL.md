# Search & Explore IndieTool Directory

Use this skill when the user asks to:
- Find indie tools or SaaS products for a specific task (e.g. "find an SEO tool", "find an AI video generator").
- Explore categories of software on IndieTool.
- View today's top featured products and launch winners.

## Available Tools

1. **`search_tools`**:
   - Query: Free-form keyword or specific product name.
   - Category: Optional category filter.
   - Limit: Number of results (default 5, up to 20).
   - Format results cleanly with their website link, DR authority, pricing, and IndieTool review.

2. **`get_featured_startups`**:
   - Fetches the current featured startups and launch winners curated on IndieTool.
   - Displays their pitch and backlinks.

3. **`list_categories`**:
   - Returns all active categories available on IndieTool.
